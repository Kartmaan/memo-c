**Commande pour compiler** : `gcc -Wall -Wextra <nomFichier.c> -o <nomFichier>`
- `gcc` : C'est le compilateur (GNU Compiler Collection). C'est le programme qui traduit ton code C 
(lisible par un humain) en langage machine (exécutable par le processeur).
- `-Wall` : Active tous les avertissements de compilation.
- `-Wextra` : Active des avertissements supplémentaires.
- `./<nomFichier>` : Fichier source C que l'on souhaite compiler (par exemple main.c).
- `-o <nomFichier>` : Spécifie le nom du fichier exécutable généré après la compilation. `-o` signifie "output" (sortie) il indique le nom que l'on souhaite donner au fichier exécutable final.
